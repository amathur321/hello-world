# Usage review → taxonomy

A ~15-minute skim of how you've actually been using Claude, so your categories
come **bottom-up from real patterns** instead of guessed. Fill this in, hand it
back, and Claude turns it into the constellation taxonomy + backfills the map.

**Where to look:** `claude.ai/code` (Claude Code sessions) · `claude.ai` (chat
history sidebar) · your Cowork session list. Don't be exhaustive — capture the
threads that are *alive* or that you don't want to lose.
